# Football Analytics Viewer

Visor web de fútbol con datos reales de API-Football, análisis estadístico propio, mercados de goles/córners/tarjetas, cuotas disponibles del proveedor y lectura en vivo.

> Las probabilidades son estimaciones estadísticas, no garantías ni consejos de apuesta.

El proyecto está preparado para desplegar el frontend como sitio estático y el servidor Node.js por separado. La API key debe permanecer únicamente en el backend.
